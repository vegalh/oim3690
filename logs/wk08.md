# OIM3690 2026 Fall Week 08

## What I built

Back in `oim3690` this week:

- Fixed an overflow bug on Screen 2 of my lightning talk deck (`lightningtalk2.html`), where the phone frame showing my live RootMap demo was actually taller than the space it had, so the outside border of the phone got cut off at the bottom instead of fully containing the screen. Raising `.phone-frame`'s height clamp from `clamp(460px, 80vh, 880px)` to `clamp(460px, 90vh, 960px)` in `css/lightningtalk2.css` fixed it.
- Redesigned `index.html` into an actual personal/portfolio homepage instead of just the castle-loading hero it used to be: added a "Featured Projects" card grid (RootMap, Peninsula Montessori Lesson Finder, Housing Points Tracker, To-Do List) with a collapsible "more coursework pages" mini-grid underneath, a Lightning Talks section, and a Weekly Logs timeline that links each week out to its rendered markdown file on GitHub instead of me writing a second markdown parser. Also linked Lesson Prep Planner (Mini Project 2) from the README.
- `playlist.html` and `js/playlist.js` are the **Playlist** exercise from class on 10/20: an array of songs, and a `for` loop I wrote that adds each one to the page as an `<li>`, with an `if` inside the loop that flags any title containing "Remix." Started with placeholder song titles, then swapped them for real **Frente!** songs (Bizarre Love Triangle, Accidently Kelly Street, Ordinary Angels, Labour of Love) once placeholder data felt less fun than an actual playlist.

## What gave me trouble

- Getting the phone frame's aspect ratio right across different screen sizes. I had to actually test at 1366×768 and 1920×1080, and resize the window in between, to make sure the "phone" inside stayed proportioned like a real phone (390:844) instead of just eyeballing it at one resolution and assuming it held everywhere else.
- I made almost the exact same CSS mistake from Week 04 again without noticing right away: I gave one of the new `index.html` sections (`.section-work.alt`) a background color that was literally the same variable as the page's own background, so the section band was invisible even though the HTML and CSS both looked "correct" on paper. Only caught it by actually looking at the rendered page and noticing nothing visually separated the sections, then swapped in a distinct hardcoded shade.
- For the playlist, I didn't want to just invent a fake "Remix" title and call it a real song, so I looked up Frente!'s actual discography (`Marvin the Album`, 1992) to get the correct spelling of "Accidently Kelly Street" — the band intentionally left out the second "a," which isn't a typo I would've guessed on my own — before writing it into the array.

Nice to have a week where the `oim3690` work and Mini Project 2 line up — the lightning talk is literally about AI-assisted building, and I used that same plan-first → build → verify-in-the-browser workflow on both the `index.html` redesign and the phone-frame fix.
