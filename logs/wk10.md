# OIM3690 2026 Fall Week 10

## What I built

- Added an **Ask AI** page (`ai-chat.html`) with a Vercel serverless function (`api/ask.js`) for Checkpoint 5. The page sends my prompt to `/api/ask`, and the function calls OpenRouter with the API key stored in Vercel's Environment Variables, so the key is never in my repo.
- Gave the AI a personality with the `instructions` in `api/ask.js`: a strict but kind wizard professor who checks whether I finished my tasks, awards house points for finished work, takes points away for excuses, and ends every answer with a question about what I still have to finish. Then restyled `ai-chat.html` as an animated wizard's study ("The Professor's Study") to match.
- Built `llm-test.html`, a bare-bones test page for `/api/ask` that pulls the reply text out of `data.output` (the item with `type === 'message'`), so I could check the function worked before styling anything.
- Built `fetch-fun.html` (**Fetch Something Fun**), which uses the free Open-Meteo API to show the current temperature near Peninsula Montessori in Newton, with a "Loading..." state and a friendly error message inside `try/catch`.
- Built `post-message.html` (**Message Board**), which `POST`s a message to the course server with `fetch`, sending JSON in the body and my GitHub username in the `X-Token` header. It disables the button while posting and won't send an empty message.
- Linked the new pages from the README.

## What gave me trouble

- `/api/ask` only works on the deployed Vercel link, not in Live Server or on GitHub Pages, because those only serve static files and can't run the function. At first it just looked broken, until I realized I had to test on the Vercel URL.
- The function had to live in a folder named `api` at the root of the repo for Vercel to find it, so I had to move `ask.js` there.
- The model's response comes back as a nested object, not plain text, so I had to dig through `data.output` to find the message and then `content[0].text` before anything showed up on the page.

Fun to see how the same `fetch` → `response.ok` check → `response.json()` pattern shows up in all three pages this week: reading weather data, posting a message, and talking to an AI.
