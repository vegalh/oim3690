# OIM3690 2026 Fall Week 03

## What I built

This week I worked on a few different pages:

- A **lightning talk slide deck** (`lightningtalk.html`) titled "Are We Still Coding, or Are We Managing AI Coders?" — a full-screen, one-slide-at-a-time deck built with just CSS transforms and transitions instead of a slideshow library.
- More of my **about-me page** (`about-me.html`) and a new **application.html** page.
- I also let AI talk me into scaffolding a whole separate React + Vite + TypeScript + shadcn project in a `web/` folder, complete with `package.json`, `tsconfig`, and a bunch of generated components. After looking through it, I decided it didn't fit what I'm actually trying to learn this semester, so I deleted the whole `web/` folder and committed that removal.

## What gave me trouble

The biggest thing that gave me trouble was realizing how easy it is to let AI push me toward a much bigger, more complicated setup (React, TypeScript, npm packages) than I actually need for a plain HTML/CSS/JS class project. It took me a while to notice the `web/` folder wasn't helping me learn and to decide to just remove it.

Other things that gave me trouble:

- reading through the CSS transitions in `lightningtalk.html` to understand how the "slides" move in and out of view
- deciding when a suggestion from AI is actually useful versus just extra complexity I'd have to maintain
- remembering how to commit my file
- saving my progress while working

My process for saving my work is:

1. Make changes to the project.
2. Save the file.
3. Commit the changes in [GitHub Desktop](https://desktop.github.com/).

This week I also learned how to open my pages on a public domain instead of just running them on localhost, which is encouraging me to keep working since I can actually share what I've built with other people.
