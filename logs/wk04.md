# OIM3690 2026 Fall Week 04

## What I built

This week was more about cleaning up than building new pages:

- I had a `redesign` branch sitting around from earlier experiments, so I merged it into `main` and deleted it so I only have one branch to keep track of.
- The bigger project was pulling every page's internal `<style>` block out of the HTML and moving all of it into the shared `css/styles.css` file instead. All seven pages (`index.html`, `about-me.html`, `cv.html`, `application.html`, `hello.html`, `try.html`, `lightningtalk.html`) now link to `css/styles.css` instead of carrying their own styles.
- Since a few pages reused the same variable names (like `--ink` or `--gold`) for completely different color schemes, I gave each page its own class on the `<body>` tag (like `page-cv` or `page-about-me`) so the rules don't bleed into each other now that they all live in one file.
- I added three new shared rules to `styles.css`: one for `h1`, one for a class I made up called `.callout` (I used it on my about-me page for a little highlighted note), and one `a:hover` rule.

## What gave me trouble

- Figuring out that just copy-pasting all the CSS into one file would break things, because different pages had defined the same variable names with different values. I had to scope each page's rules under its own class instead of dumping everything in unscoped.
- Double-checking that nothing got lost or left un-scoped in the process — one of my pages (`lightningtalk.html`) had a stray apostrophe in a CSS comment that confused the parser I was using, so part of that file's rules didn't get scoped correctly the first time and I had to catch and fix it.
- Making sure every page still looked and behaved exactly the same after the move, since a couple of these pages have animations and interactive JS that depend on specific class names.
- Remembering how to commit my file
- Saving my progress while working

My process for saving my work is:

1. Make changes to the project.
2. Save the file.
3. Commit the changes in [GitHub Desktop](https://desktop.github.com/).

This week felt less like writing new code and more like being a good "housekeeper" for code I'd already written, which is a different skill than I expected to be practicing in this class.
