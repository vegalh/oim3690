## What I built

This week I worked on two projects:

- A **housing points tracker** (`try.html`) for my community, where residents can be added or removed, and activities like meetings, retreats, and absences add or subtract points automatically. It saves everything to `localStorage` so the data stays even after closing the browser. But it is still a very rough project, I need to find a way to plug in the previous data.

## What gave me trouble

I try to read the code that AI generates for me line by line so I actually understand what each part does, instead of just copying and pasting it. That was slow going, especially with the `localStorage` logic and the CSS used to build the castle out of plain shapes.

The parts that gave me the most trouble were:

- reading and understanding JavaScript I didn't write myself (like the `render()` function that recalculates totals every time)
- figuring out how CSS `clip-path` and `border-radius` were used to fake 3D shapes like the castle roof and door
- remembering how to commit my file
- saving my progress while working


My process for saving my work is:

1. Make changes to the project.
2. Save the file.
3. Commit the changes in [GitHub Desktop](https://desktop.github.com/).

The word `commit` is still new to me, but I am learning that it helps record my progress. I'm also getting more comfortable asking the AI to explain a block of code instead of just accepting it, which is helping me actually learn instead of just producing something that works.
